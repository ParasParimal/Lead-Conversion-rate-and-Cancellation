ElectricPe Lead Conversion Dashboard
Overview

Interactive Excel dashboard to analyze lead conversion, turnaround time (TAT), and cancellations across stores. Provides insights to identify issues like model unavailability and pricing gaps, enabling data-driven improvements.

Features

Track lead conversions, TAT, and cancellations

Highlight store-wise performance and operational gaps

Generate actionable insights to optimize sales

Impact

Projected 15% increase in conversions

Predicted 30% reduction in cancellations

Usage

Open ElectricPe_Dashboard.xlsx in Excel

Use filters and slicers to explore data by store, model, or period

Analyze charts and tables for actionable insights

Technologies

Microsoft Excel (Pivot Tables, Charts, Formulas, Conditional Formatting)
